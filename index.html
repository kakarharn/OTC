Reset Mechanism

Gas Turbine OTC Controller Reset ส่งผลอย่างไร?

OTC Controller ที่ถูก Reset ต้องใช้เวลากลับไปพร้อมรับ Load ถ้า Startup เสร็จก่อน จะเกิด MW Loss และต้องรอ Resumption เพิ่มก่อนคืนค่าความพร้อม

OTC Controller Reset
Controller เริ่มกระบวนการ Recovery ใหม่
Startup in Progress
เครื่องดำเนินการ Startup ขณะที่ OTC Controller กำลัง Recovery
Startup Complete
Startup Process เสร็จสิ้น แต่ OTC Controller อาจยังไม่พร้อมรับ Load เต็มที่
Reduced Load Capability
กำลังผลิตที่สามารถทำได้อาจต่ำกว่าระดับอ้างอิง
OTC Controller Ready
Controller กลับสู่ระดับพร้อมรับ Load
Resumption Process
ดำเนินกระบวนการคืนความพร้อมตามขั้นตอน
NCC Accepted / Availability Restored
NCC รับคืนเครื่อง และคืนค่าความพร้อมให้

Emergency Response Impact

ผลของการตอบสนองด้วย Adjust TU ทันทีที่พบปัญหา

Adjust TU Override ลดผลกระทบได้มากแค่ไหน เทียบกับปล่อยให้ Recovery ตามปกติ

เทียบ Current Configuration (ไม่ตอบสนอง) กับ Adjust TU Override (มาตรการฉุกเฉินชั่วคราว) เป็น Scenario สำหรับศึกษาเปรียบเทียบเท่านั้น ต้องผ่านอนุมัติเป็น SOP ก่อนใช้จริง

Adjust TU ทำให้ OTC กลับ Reference ได้ภายในไม่กี่วินาที เร็วกว่า Startup ทุก Condition จึงไม่เกิด Post Event และไม่มีค่าปรับเลย ต่างจาก Current Configuration ที่ปล่อยตามปกติแล้วโดนบทปรับตามเวลาที่เกิดขึ้นจริง
